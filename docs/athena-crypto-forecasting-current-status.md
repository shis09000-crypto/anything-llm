# Athena 加密市场量化工具现状、完成情况与后续方向

更新日期：2026-07-30
当前公开定位：`monitoring_only`（量化数据监测，不提供直接行情方向预测）

## 1. 当前结论

Athena 的加密货币公开市场工具已经具备较完整的数据采集、量化计算、证据关联和审计能力，但现阶段的历史验证没有证明方向模型能在手续费、滑点和资金费率之后稳定优于简单基线。

因此，当前产品边界固定为：

- `crypto_price` 保持公开现货价格查询。
- `crypto_market_snapshot` 的 `simple` 模式保持原有轻量行情快照。
- `crypto_market_snapshot` 的 `analysis` 模式作为量化数据监测工具。
- 暂不向普通用户或解释模型公开上涨/区间/下跌概率、候选方向、收益分位数、价格目标或交易指令。
- 历史模型、特征快照、Prediction Passport 和审计结果继续保留，供以后复算和研究，不能作为已获准的生产预测。

这不是把失败模型包装成“保守预测”，而是明确承认：当前证据足以支持市场状态监测，尚不足以支持可执行的方向预测。

## 2. 公开工具现在提供什么

### 2.1 简易模式

保持原有兼容行为：

- 当前价格、24 小时涨跌、成交量。
- 买一、卖一和点差。
- Gate 与 Binance 的公开行情交叉校验及降级状态。

### 2.2 分析模式

分析模式继续提供以下可复算监测数据：

- `1h`、`4h`、`1d`、自然周 `1w` 的已收盘 OHLCV。
- SMA 5/10/30、EMA 12/26、MACD、RSI、ATR、ADX、BOLL 和 Stochastic。
- OBV、滚动 VWAP、成交量 SMA20、量比、成交量 Z-Score。
- CMF、MFI、累积派发线及短期斜率。
- Donchian、线性回归斜率与 R²、效率比率、已确认高低点结构。
- Fibonacci、20/50 根区间、支撑阻力参考位。
- 现货主动成交、CVD、点差、微价格、不同 bps 深度和盘口失衡。
- 公开永续合约的 OI、资金费率、基差、多空结构和爆仓旁证。
- 数据新鲜度、来源失败、形成中 K 线排除、样本覆盖和计算输入 SHA。

工具可以报告“某个已定义条件当前是否触发、是否已被收盘数据确认、旁证是否支持或冲突”，但必须同时说明这些是事件监测，不是对未来方向的判断。

## 3. 已经完成的工程成果

### 3.1 数据与时间合同

- 建立量化专用 SQLite WAL 数据域，不写入业务数据库或 Operations ClickHouse。
- 建立来源、交易所时间、接收时间、`availableAtMs`、回填和质量状态合同。
- 指标和训练只使用已收盘且在决策时点已经可用的数据。
- 历史 Binance 公开档案按校验清单回填，并保留数据集 SHA。
- BTC、ETH、SOL 的现货、USD-M 合约、标记价格和资金费率数据已形成可继续使用的数据基础。

### 3.2 特征、模型和治理基础

- 完成 Feature Registry、成本模型版本化和 Python/Node 特征顺序合同。
- 完成 Prediction Passport、特征快照、模型与数据集 SHA 关联。
- 完成 ONNX 运行时边界和 ML-DSA-65 模型清单验签。
- 完成 Shadow、弃权、漂移、签名失败和数据质量阻断机制。
- 完成 v3/v4 的独立历史审计框架，以及 v5 的成本感知首次触碰标签、两层模型和独立审计代码。

### 3.3 真实性与安全边界

- v4 独立审计结论为 `FAIL`，没有被提升为生产方向模型。
- 当前签名模型只保留为 Shadow 研究资产，公开结果始终弃权。
- v5 在云端训练阶段因生产主机资源约束停止；停止前没有生成候选模型文件，也没有产生可被误加载的未签名模型。
- 完整数据快照、开发期隔离数据和清单已保留，可在合适的训练环境恢复；线上业务服务未因本次停止受损。

## 4. 本次监测模式治理

公开链路增加统一策略：

```json
{
  "mode": "monitoring_only",
  "directDirectionalPrediction": false,
  "directionalProbabilitiesExposed": false,
  "returnTargetsExposed": false,
  "tradeInstructionsExposed": false,
  "researchArtifactsRetained": true,
  "reason": "forecast_models_not_promoted"
}
```

治理覆盖以下出口：

1. 普通认证的最新预测和历史预测列表。
2. Prediction Passport 详情的公开视图。
3. Agent 获得的工具结果投影。
4. 最终用户可见的分析报告。

公开视图会删除：

- `probabilities`
- `candidateState`
- `predictedState`
- `actionProbability`
- `tradeabilityProbability`
- `conditionalDirectionProbability`
- `conditionalSideProbability`
- `returnQuantiles`
- 方向驱动因素和执行闸门

底层审计库不删除这些历史研究字段，以免破坏真实性复算；公开 API 和 Agent 链路只能取得脱敏后的监测视图。

分析报告不再调用 LLM 判断方向，直接由确定性服务端模板生成。这同时降低推理费用、消除自由文本夸大，也保证报告中的数字和路径来自结构化工具结果。

## 5. 当前限制

- 已完成的方向模型尚未证明存在稳定、可泛化、成本后为正的优势。
- 现有生产云服务器承担业务 API、数据采集和伴随服务，不适合继续执行高内存全量训练。
- 盘口、订单流、期权曲面和部分衍生品证据的历史长度仍不足以进入正式模型。
- 三个币种和单一加密市场的样本制度有限，容易把某一阶段的行情结构误认为长期规律。
- 量化指标高度相关，增加指标数量不等于增加独立信息；未经消融和时间隔离的指标不能强制入模。
- 条件触发、趋势状态和 Fibonacci 参考位只能描述当前结构，不能证明未来一定延续或反转。

## 6. 以后如何继续改善

恢复预测研究前，应先满足训练环境和证据条件，而不是降低验收门槛。

### 6.1 训练资源方案

优先顺序：

1. 使用临时、按需的高内存训练实例，训练完成即释放，不新增常驻服务器。
2. 从云端冻结数据快照只读导出，训练后仅上传签名模型、校准器、报告和清单。
3. 将特征物化、候选训练和独立审计拆成可恢复的阶段任务，避免一次占满生产主机。
4. 训练完成后删除临时数据与依赖，本机和生产机都不承担常驻训练。

### 6.2 数据积累

- 继续低成本积累 BTC、ETH、SOL 的一分钟盘口与订单流聚合。
- 衍生品、微观结构和期权数据达到至少 180 天、95% 覆盖率、低于 0.5% 缺口率后才允许参加消融。
- 对来源切换、时间戳、修订和延迟继续执行 `availableAtMs <= decisionAtMs`。
- 不补造缺失的历史盘口、资金费率、链上或宏观发布时点。

### 6.3 模型研究

- 保持“机会/可交易性 → 条件方向”的两层结构，先判断是否值得交易，再研究方向。
- 分周期建立独立特征集合，避免短周期量能污染长周期。
- 使用特征族消融、连续时间块置换和条件敏感度，而不是简单指标投票。
- 继续与固定多头、固定空头、持续性、动量和随机基线在完全相同样本上比较。
- 阈值只能在冻结的校准区间选择，审计区间不得反向调参。

### 6.4 重新开放方向预测的硬条件

只有同时满足以下条件，才能单独讨论某个周期是否从监测模式升级：

- 独立审计不存在时间泄漏、成本遗漏或 Python/Node 不一致。
- 非弃权覆盖率、精选准确率、MCC、Brier Skill 和 ECE 达标。
- 扣除手续费、滑点和真实资金费率后，分块 Bootstrap 95% 下界大于零。
- BTC、ETH、SOL 和主要波动制度没有显著退化。
- 前瞻 Shadow 达到规定时长和非重叠结算样本。
- 模型、Registry、校准器和数据集清单全部通过 ML-DSA-65 验签。
- 由人工明确批准激活；代码不得自动把 Shadow 提升为 Active。

在这些条件满足前，`monitoring_only` 是正式产品状态，而不是临时错误状态。

## 7. 运维与资源边界

- 量化数据域继续限制在 2 GiB。
- 生产磁盘始终预留至少 12 GiB。
- 采集和监测不得影响业务 API、Operations consumer、NATS ACK 或 ClickHouse。
- 训练任务不得再在生产主机无资源预算保护地启动。
- 运维事件只记录低基数状态、延迟、缺口、弃权和验签结果，不上传原始行情正文或模型自由文本。

## 8. 当前可接受的用户表达

允许：

- “4 小时已收盘数据当前为高点、低点抬高结构。”
- “5 分钟主动买入占比为 56%，但盘口深度旁证冲突。”
- “上轨突破监测条件已触发，尚未得到收盘数据确认。”
- “资金费率处于高位，表示仓位拥挤风险上升。”

禁止：

- “未来 4 小时大概率上涨/下跌。”
- “建议做多/做空。”
- “目标价为某个 Fibonacci 位。”
- “机构正在吸筹/出货。”
- “该信号胜率高”或其他未经独立审计支持的准确率表达。

## 9. 一句话状态

当前工具是一个具备多周期量价、微观结构、衍生品旁证和完整回溯能力的公开市场监测系统；预测研究资产已经保留，但由于尚未证明成本后优势，所有直接方向输出已关闭。
